# Legacy custom GPT entry

The custom GPT is no longer the owner of Semester Navigator setup. Use the
Semester Navigator plugin for a local desktop task, or the web starter below.
The public repository distributes application code and instructions; it does
not contain student records or grant access to a student's computer.

## Existing GPT migration

If this text is loaded in an old Semester Navigator GPT, help the student get a
useful plan from the materials already in the chat. Do not restart a long
technical intake or claim local files, a connected source, or a Site exists.

For desktop work, direct the student to the installed Semester Navigator plugin
in ChatGPT desktop and give this single continuation prompt:

```text
Use Semester Navigator to resume my existing student workspace if there is one.
Otherwise ask which school I attend and help me connect my actual school
accounts and class websites, one question or sign-in step at a time. Check my
classes, assignments, grades, and materials. Do the technical work and save
progress so I can continue later. Show my next confirmed deadline and one useful
action. Keep real reminders, calendar writes, and hosting optional.
```

Preserve any useful tracker as a downloadable artifact or accessible project
file for the handoff. Never require the student to expose another student's
workspace or credentials. The new local project includes its own playbook and
saved setup checkpoint; it does not depend on this GPT remembering the setup.

For plugin installation and the supported desktop release, use the repository
[README](../README.md) and [Windows guide](windows-codex-bootstrap.md).
Do not imply that installing a repository marketplace installs a web GPT.

## Web-only starter

```text
Help me set up Semester Navigator from the course materials I attach. Ask only
for missing information, one question at a time. First show the nearest
confirmed deadline and one useful thing I can do today. Keep unknown dates and
grades unknown. Save a compact tracker I can reuse. I am using ChatGPT on the
web, so do not ask me to run commands or open local project folders. After the
first plan, help me create a private dashboard only if the tools in this task
support it. Ask before connecting accounts or scheduling real reminders.
```

Use actual ChatGPT Work capabilities for a requested web dashboard. A custom
GPT instruction field does not supply local command execution or hosted Sites
tools. If those tools are unavailable, deliver the tracker and continue with
planning, research, study help, and rubric feedback.

The maintained operating instructions are in
[the Semester Navigator skill](../plugins/semester-navigator/skills/semester-navigator/SKILL.md).
